## Featured Projects

### Smart Motorcycle Helmet
Technologies: Arduino UNO, GPS, GSM, MQ-3, Vibration Sensor

- Designed an accident-detection system using vibration and impact sensors to trigger automated emergency responses
- Integrated GPS and GSM modules for real-time live location tracking and emergency alert transmission to contacts
- Implemented alcohol-detection logic using the MQ-3 sensor to prevent drunk riding and enhance road safety

### Pulse Oximeter System
Technologies: Arduino, MAX30102, Signal Processing, IoT

- Engineered a low-cost pulse oximeter for real-time SpO2 and heart rate monitoring with 95% accuracy
- Presented at the ICAST 2024–25 International Conference
- Published by CRC Press, Taylor & Francis in June 2025

### Smart Roof Automation System
Technologies: STM32, DHT22, YL-83 Rain Sensor, Embedded C

- Built a weather-responsive roof automation system using an STM32 microcontroller
- Integrated DHT22 humidity and YL-83 rain sensors for real-time environmental sensing
- Programmed motor driver logic to automatically extend and retract the roof based on real-time conditions
- Eliminated manual intervention by making the system self-adapt to rain, humidity, and sunlight conditions
